# Design Workspace

This directory will hold approved visual-system documents, interaction studies, and selected mockups.

The first exploration should present exactly three distinct directions using the same representative states:

1. Atlas overview
2. House place page
3. Room with loci
4. Memory detail
5. Recall walk
6. Strong, uncertain, fading, empty, and reduced-motion states

Do not commit random inspiration dumps. Every reference should identify what is worth learning from it and what should not be copied.
