# Research Workspace

Research should answer decisions that change the product.

Priority questions:

- What makes method-of-loci practice effective over repeated use?
- How should free recall, confidence, cueing, and recognition be distinguished?
- Which spaced-retrieval model is appropriate for heterogeneous personal memories?
- How does autobiographical recall differ from memorizing factual material or passages?
- When do AI-generated mnemonic suggestions help, and when might they weaken encoding?
- How can memory decay be visualized without implying false scientific precision?
- What privacy model is credible for intensely personal archives?

Each research note should separate evidence, inference, product implication, and unresolved uncertainty.
